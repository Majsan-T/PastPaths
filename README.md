# PastPaths – Genealogy Desktop App

**A free, local genealogy program for Windows – built with research in focus. No cloud services, no subscriptions, no login.**

> *"I have done genealogy research for a long time and tested many different applications. Some felt outdated, while others required expensive subscriptions where my data ended up in the cloud. I built PastPaths because I wanted a fast, clean tool where all photos, stories, and sources can be sorted and organized."*
> — **Maria Tingvall**, creator of PastPaths

## ✨ Why PastPaths?

- 💾 **Everything stays on your computer** – a local SQLite database, no cloud services, no telemetry
- 🌳 **Bring your existing tree** – GEDCOM import/export (standard, Ancestry, MyHeritage, TNG and others), and an import can be undone
- 📸 **Photos, documents, and stories together** – one photo can be linked to multiple persons, events, and places, and the built-in blog lets you write longer family stories
- 📖 **Show where your information comes from** – source citations on persons, events, places, and blog posts
- 📦 **Place Library** – ready-made packs of Swedish counties, historical counties, provinces, dioceses, and more, kept up to date right in the program
- 🌐 **Swedish and English interface**, switchable anytime

<summary><strong>All features</strong></summary>

- 👥 Persons, events, and relationships — indirect kinship (cousin, grandmother, brother-in-law) is worked out automatically
- 📍 Places with hierarchical browsing (country → region → county → parish/city) and GPS coordinates
- 📊 Family tree, timeline, and statistics for persons and places
- 📅 Calendar — today's birthdays and events, regardless of year
- 🗺️ Interactive map
- 🏷️ Tags and categories to organize and find things quickly
- 🔁 Duplicate detection with automatic identification and merging
- 📄 Reports as PDF (ancestor chart, descendant chart, family group sheet, source list, person profile)

## 📥 Installation

1. Download the latest installer from [pastpaths.se/en/download](https://pastpaths.se/en/download/) (or directly from [Releases](https://github.com/Majsan-T/PastPaths/releases/latest))
2. Run the installer and follow the setup wizard
3. Launch the app from the desktop shortcut

**System requirements:** Windows 10/11 (64-bit) · 4 GB RAM (8 GB recommended) · 500 MB free disk space

> Installs to `%LOCALAPPDATA%\PastPaths\` by default – no administrator rights required.

Upgrading? Just run the new installer – your data stays in place, and the installer offers to make a backup first.
