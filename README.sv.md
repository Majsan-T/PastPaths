# PastPaths – Släktforskningsprogram för desktop

**Ett gratis, lokalt släktforskningsprogram för Windows – utvecklat med forskning i fokus. Inga molntjänster, inga abonnemang, ingen inloggning.**

## ✨ Varför PastPaths?

- 💾 **Allt stannar på din dator** – lokal SQLite-databas, inga molntjänster, ingen telemetri
- 🌳 **Ta med ditt befintliga träd** – GEDCOM import/export (standard, Ancestry, MyHeritage, TNG med flera), och en import kan ångras
- 📸 **Foton, dokument och berättelser tillsammans** – en bild kan kopplas till flera personer, händelser och platser, och i den inbyggda bloggen skriver du längre släktberättelser
- 📖 **Visa var uppgifterna kommer ifrån** – källhänvisningar på personer, händelser, platser och blogginlägg
- 📦 **Platsbibliotek** – färdiga paket med svenska län, historiska län, landskap, stift med mera, som hålls uppdaterade direkt i programmet
- 🌐 **Svenskt och engelskt gränssnitt**, växlingsbart när som helst

<details>
<summary><strong>Alla funktioner</strong></summary>

- 👥 Personer, händelser och relationer — indirekta släktskap (kusin, mormor, svåger) beräknas automatiskt
- 📍 Platser med hierarkisk navigering (land → region → län → församling/ort) och GPS-koordinater
- 📊 Släktträd, tidslinje samt statistik för personer och platser
- 📅 Kalender — dagens födelsedagar och händelser, oavsett år
- 🗺️ Interaktiv karta
- 🏷️ Taggar och kategorier för att organisera och hitta snabbt
- 🔁 Dubbletthantering med automatisk identifiering och sammanslagning
- 📄 Rapporter som PDF (antavla, stamtavla, familjeblad, källförteckning, personprofil)

## 📥 Installation

1. Ladda ner senaste installationsfilen från [pastpaths.se/download](https://pastpaths.se/download/) (eller direkt under [Releases](https://github.com/Majsan-T/PastPaths/releases/latest))
2. Kör installationsprogrammet och följ guiden
3. Starta appen via genvägen på skrivbordet

**Systemkrav:** Windows 10/11 (64-bit) · 4 GB RAM (8 GB rekommenderas) · 500 MB diskutrymme

> Installeras som standard till `%LOCALAPPDATA%\PastPaths\` – kräver inte administratörsbehörighet.

Uppgraderar du? Kör bara det nya installationsprogrammet – din data ligger kvar, och installationsprogrammet erbjuder att göra en säkerhetskopia först.

📬 **Få besked om nya versioner:** [anmäl dig till nyhetslistan](https://pastpaths.se/mailman/listinfo/pastpaths_releases_pastpaths.se) (några mejl per år), eller klicka på **Watch → Custom → Releases** här på GitHub.//
